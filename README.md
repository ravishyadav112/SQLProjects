# Online Sales Data Analysis

This repository contains analysis of an online sales database. The analysis focuses on revenue trends, product performance, and regional sales data.

## Database Structure

The analysis is based on an `online_sales_data` table that contains transaction information for online sales, including:
- Transaction dates
- Transaction IDs
- Product categories
- Units sold
- Revenue amounts
- Regional information

## Available Analyses

The repository includes the following analyses of the online sales data:

### 1. Monthly Revenue and Order Volume

Calculates total revenue and total orders for each month, allowing for trend analysis over time.

### 2. Regional Monthly Revenue

Breaks down monthly revenue by region to identify geographical performance patterns.

### 3. Top-Selling Product Category by Month

Identifies the highest-revenue product category for each month, showing which products are driving sales.

### 4. Month-over-Month Revenue Change

Calculates the difference in revenue between consecutive months to track growth or decline.

### 5. Average Order Value by Month

Calculates the average value of each order by month to understand customer spending patterns.

### 6. Monthly Order Volume by Category

Shows the number of orders for each product category by month, tracking category popularity.

### 7. Most Popular Product by Month

Identifies the product category with the highest order count each month, which may differ from the highest revenue category.

## Insights

This analysis helps in:
- Identifying seasonal trends in sales
- Understanding which product categories perform best in different time periods
- Recognizing regional differences in customer preferences
- Monitoring sales growth or decline over time
- Tracking changes in customer purchasing behavior
